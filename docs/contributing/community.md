# Community

guilds.run has three public channels besides this repository.

- [X](https://x.com/guildsrun) is the public account.
- [Discord](https://discord.gg/aqp5aPq9Uh) is the community server.
- [Product Hunt](https://www.producthunt.com/p/guilds-run) is the
  product listing.

Code changes are pull requests against `main`. The licence, the
check, and how a change lands are on
[Contributing](../CONTRIBUTING.md).

Security issues are reported privately:
[SECURITY.md](../../SECURITY.md).
