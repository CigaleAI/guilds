# Security

Report a vulnerability privately through GitHub's private
vulnerability reporting on this repository (the Security tab,
**Report a vulnerability**).

Do not open a public issue or pull request for it.

Include what is affected, how to reproduce it, and what an
attacker gains.

The `main` branch is the supported version.

Every security issue found, fixed or still open, is recorded with
its history in the
[security register](docs/architecture/security-register.md).

What the system assumes about its deployment is the trust
boundary in [System](docs/architecture/system.md).
